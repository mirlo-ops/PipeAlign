# PipeAlign / ТрубоНастрой

**Демонстрационный ассистент переналадки косовалковой правильной машины.**

Демо-прототип цифрового советчика наладчика: программа по параметрам трубы
(диаметр, стенка, марка стали, операция, остаточный изгиб) рассчитывает
уставку между валками, количество проходов и скорость подачи, объясняет
решение человеческим языком и оценивает экономию времени по сравнению с
ручной переналадкой.

> **Дисклеймер.** Демонстрационный прототип. Расчёты модельные.
> Реальное управление оборудованием требует отдельной валидации.
> Программа не обращается к станку, не делает сетевых запросов и не передаёт
> данные за пределы компьютера. Вымышленное производство: ООО «СтальТрубПром».

---

## 1. Назначение

На участке подготовки труб после гибки, сварки, механо- и термообработки
оператор вручную подбирает зазор между валками правильной машины, ориентируясь
на опыт и таблицы. Это приводит к:

* затратам времени на переналадку (демо-оценка — около 40 минут на смену);
* нескольким пробным прогонам до попадания в допуск;
* браку по кривизне из-за неверной уставки;
* зависимости результата от конкретного оператора.

PipeAlign решает ровно эту задачу: получает параметры трубы и выдаёт готовую
уставку с обоснованием.

## 2. Стек

| Компонент | Назначение |
|-----------|------------|
| Python 3.10+ | язык приложения |
| PySide6 (QtWidgets) | настольный интерфейс, без QML |
| PyInstaller | сборка Windows `.exe` |
| JSON | рецепты, журнал, отчёты |
| стандартная библиотека | `json`, `csv`, `dataclasses`, `datetime`, `pathlib`, `sys` |

Не используются: Flask, FastAPI, React, Vue, Electron, WebSocket, HTTP-серверы,
Docker, СУБД. Программа полностью автономна.

## 3. Запуск из исходников

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

При запуске появляется окно входа. Демонстрационные учётные записи:

| Логин | Пароль | Сотрудник | Роль |
| --- | --- | --- | --- |
| `akulov` | `1234` | Акулов Л.И. | Оператор станка |
| `korablev` | `4321` | Кораблев М.Д. | Контролёр ОТК |

Логин можно ввести и полным ФИО — «Акулов Л.И.» или просто «Акулов»
сработает так же. Роль выбирается не вручную, а определяется учётной
записью, поэтому оператор не может случайно получить права контролёра.

Что отличается у ролей:

| Раздел | Оператор станка | Контролёр ОТК |
| --- | --- | --- |
| Заказ и операция | скрыт (данные с наряда) | видна |
| Ожидаемый эффект | скрыт (экономика проекта) | видна |
| Расчёт, схема, предупреждения | видна | видна |
| Отчёт, журнал, «О системе» | видна | видна |

Расчёт от роли не зависит: обе роли получают одну и ту же уставку.

Смена сотрудника: кнопка **«Сменить пользователя»** в правой части строки
состояния (рядом с именем) или **Ctrl+L**. После подтверждения программа
возвращает окно входа, а новое окно открывается уже с правами нового
сотрудника: записи в журнале сохраняются, несохранённый расчёт и выбранный
заказ сбрасываются. Полный **«Выход»** (Alt+F4) закрывает программу.

> Авторизация здесь — **учебная заглушка**. Пароли лежат в исходном коде
> (`app/services/auth_service.py`) открытым текстом и сравниваются напрямую.
> В настоящей системе нужен хеш пароля с солью, хранение учётных записей вне
> репозитория и журнал входов.

Проверка расчётного ядра без интерфейса:

```bat
python -m pytest tests -q
```

## 4. Сборка .exe (Windows)

```bat
scripts\build_windows.bat
```

Скрипт вызывает PyInstaller и собирает
`dist\PipeAlign\PipeAlign.exe`. Журнал и отчёты пишутся не рядом с `.exe`,
а в `%APPDATA%\PipeAlign`, поэтому программа запускается даже из
`Program Files`.

Скрипт можно запускать из любого каталога и с сетевого диска: он сам
переходит в корень проекта и ищет интерпретатор сначала как `python`,
затем как `py -3`.

Быстрый запуск из исходников: `scripts\run_windows.bat`.

## 6. Демонстрационный сценарий

Кнопка **«Демо-сценарий»** на вкладке «Переналадка» автоматически, без
блокировки интерфейса (через `QTimer.singleShot`, шаги 700–1200 мс):

1. загружает демо-заказ **ДЕМО-002** (Ø57×3.5, 09Г2С, после гибки);
2. показывает предыдущий диаметр 48 мм и старую уставку 24.8 мм;
3. меняет диаметр на 57 мм — настройка становится неактуальной;
4. включает остаточный изгиб 6 мм/м;
5. выполняет расчёт: валки анимированно перемещаются в целевое положение;
6. показывает обоснование расчёта;
7. применяет настройку — валки становятся зелёными, запись уходит в журнал;
8. переключается на вкладку «Отчёт».

Дополнительно доступны:

* **«Пресет: смена диаметра 48 → 57»** — мгновенная загрузка состояния
  «до смены диаметра»;
* **«Пресет: труба погнулась после гибки»**;
* **«Симулировать ошибку наладчика»** — показывает, к чему приводит
  сохранение старой уставки при новом диаметре (занижение/перебор зазора,
  брак, потерянное время).

## 7. Расчётная модель (демонстрационная)

```
Итоговая уставка = Базовая уставка
                 + Поправка на материал
                 + Поправка на изгиб
                 + Поправка на операцию
```

* **Базовая уставка** — точное совпадение (диаметр, стенка) в `base_recipes`,
  иначе ближайший рецепт с коррекцией, иначе запасная формула
  `D/2 + 1.2 − S·0.1`.
* **Поправка на материал** — из таблицы `materials`.
* **Поправка на изгиб** — линейная интерполяция по кривой `deflection_curve`.
* **Поправка на операцию** — в версии 0.1 равна нулю (зарезервировано).
* **Проходы** — 1 / 2 / 3 прохода по величине изгиба, минимум 2 для
  тонкостенной трубы.
* **Скорость подачи** — базовые 14 м/мин минус поправки на проходы, изгиб,
  материал, стенку и операцию, не ниже 6 м/мин.
* **Прогноз остаточной кривизны** — `изгиб / (проходы × 2.5)`.
* **Уровень риска** — балльная шкала (изгиб, тонкостенность, нержавеющая
  сталь, ограничение уставки, число проходов, превышение допуска).
* **Экономия** — против фиксированной демо-нормы 40 минут на ручную переналадку.

Проверочный пример (тест `test_demo_case_57x3_5`):

| Параметр | Значение |
|----------|----------|
| Базовая уставка | 29.8 мм |
| Поправка на материал | +0.3 мм |
| Поправка на изгиб | +0.6 мм |
| Итоговая уставка | 30.7 мм |
| Проходы | 2 |
| Скорость подачи | 11.2 м/мин |
| Прогноз кривизны | 1.2 мм/м |
| Риск | низкий (1.5 балла) |

## 8. Журнал и данные

Журнал хранится в `%APPDATA%\PipeAlign\journal.json`
(резервные копии: `journal.backup.json`, повреждённый файл →
`journal.bad.json`). При недоступной записи используется домашний каталог,
затем временный. Экспорт CSV идёт в кодировке `utf-8-sig` с разделителем `;`,
чтобы корректно открываться в русском Excel.

Записываются статусы: `Расчёт`, `Применено`, `Ручная коррекция`,
`Отменено` (отмена ручной коррекции оператором).

Выгрузки с вкладки «Отчёт» получают имя с номером заказа:
`report_setup_ДЕМО-002.csv`, `report_setup_ДЕМО-002.txt`,
журнал — `journal_export.csv`.

## 9. Ограничения

* Это не система управления станком: управляющие воздействия не выполняются.
* Коэффициенты модели демонстрационные, подобраны для наглядности и не
  являются инженерно достоверными.
* Точность позиционирования валков, датчики положения и обратная связь по
  фактической кривизне не моделируются.
* Расчётная модель не сертифицирована и не предназначена для серийного
  применения без натурной валидации.

## 10. План внедрения

1. Цифровой советчик (текущая версия, режим «только рекомендация»).
2. Интеграция с заказ-нарядом и системой хранения рецептов.
3. Контроль датчиков положения валков и фактической кривизны.
4. Полуавтоматическая переналадка по подтверждению оператора.
5. Адаптивная коррекция уставки по факту изгиба (обратная связь).
